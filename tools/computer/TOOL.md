# Computer Use 领域知识（截屏 / 点击 / 输入 / 击键）

## 坐标系统
- 交给模型的截图一律缩放为 **1920x1080 逻辑画布**。
- 所有坐标基于该画布：`x ∈ [0,1920]`、`y ∈ [0,1080]`，原点在画布左上角。
- `computer_click` / `computer_virtual_click` 接收画布整数坐标，并把该点对应的真实屏幕像素一并回显（`click_screen`）；画布与真实屏幕映射是线性的，落点与实际像素一致。

## 工具区分
- **`computer_screenshot`** —— 纯截屏：捕获当前屏幕并注入上下文，供视觉定位/观察。
- **`computer_virtual_click`（虚拟点击）** —— 只在指定画布坐标处画一个红色标记并注入画面；**绝不移动真实鼠标、绝不触发任何系统点击**。用于无副作用地核对落点是否命中目标控件。
- **`computer_click`（真实点击）** —— 对系统执行一次**真实物理左键点击**（移动光标并按下），点击结束后等待 0.1s 截取点击后的**未标注**画面注入。
- **`computer_type`（输入文本）** —— 把文本输入到当前聚焦的输入框（真实系统动作）。文本**统一经剪贴板粘贴**（写入剪贴板 → Ctrl/Cmd+V），任意文本含中文均支持、内容按字面粘入（`\n`/`\r` 不会触发回车），并尽力还原用户剪贴板。
- **`computer_key`（击键）** —— 对当前聚焦窗口执行一次**真实按键/快捷键**。输入单个键名（`Return`/`Esc`/`F5`/`Space`/箭头键等）或 `+` 连接组合（`ctrl+s`、`alt+Tab`、`ctrl+shift+esc`、`ctrl+c`…）。

所有工具截图均**只注入上下文、不落盘**。

## 典型用途
- **虚拟点击用于预演**：先 `computer_screenshot` 观察画面 → `computer_virtual_click(x, y)` 得到带标记图，无副作用地核对坐标是否命中目标。
- 确认落点无误、或用户明确要求真实操作后，再调用 `computer_click(x, y)` 执行真实点击 —— 坐标基于最近一张截图（虚拟点击带标记图或真实点击回传图）推算。
- **输入文本**：先用 `computer_click` 点进目标输入框使其聚焦，再用 `computer_type("...")` 经剪贴板粘贴输入任意文本（含中文）；输入结束自动回传画面，据此判断是否输入正确。
- **触发按键/快捷键**：需要回车提交、保存（`ctrl+s`）、复制粘贴（`ctrl+c`/`ctrl+v`）、切换窗口（`alt+Tab`）等时用 `computer_key(...)`；`computer_type` 只做粘贴、不会触发回车。

## 真实操作前请自查
- 目标坐标/焦点是否来自最新一张可见截图？位置变动过大时先重新 `computer_screenshot`。
- 是否存在可能误触（删除/提交/转账/发送等高风险按钮）？不确定时先 `computer_virtual_click` 试算并向用户说明。

## 注意事项
- 截屏覆盖**主显示器**；坐标是整块屏幕坐标（含任务栏/停靠栏）。
- `computer_virtual_click` 永不执行真实操作；要在系统里真正点击用 `computer_click`，输入用 `computer_type`，快捷键用 `computer_key`，不要混淆。
- 每张截图都会进入上下文，连续反复截屏会快速消耗上下文；能依据上一次回传画面判断时就不要重复截屏。
