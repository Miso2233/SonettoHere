# Computer Use 领域知识（截屏 / 点击）

## 坐标系统
- 交给模型的截图一律缩放为 **1920x1080 逻辑画布**。
- 所有坐标基于该画布：`x ∈ [0,1920]`、`y ∈ [0,1080]`，原点在画布左上角。
- `computer_click` / `computer_virtual_click` 接收画布整数坐标，并把该点对应的真实屏幕像素一并回显（`click_screen`）；画布与真实屏幕映射是线性的，落点与实际像素一致。

## 工具区分
- **`computer_screenshot`** —— 纯截屏：捕获当前屏幕并注入上下文，供视觉定位/观察。
- **`computer_virtual_click`（虚拟点击）** —— 只在指定画布坐标处画一个红色标记、截取带标记画面注入并落盘；**绝不移动真实鼠标、绝不触发任何系统点击**。用于无副作用地核对落点是否命中目标控件。
- **`computer_click`（真实点击）** —— 对系统执行一次**真实物理左键点击**（移动光标并按下），点击结束后等待 0.1s 截取点击后的**未标注**画面注入并落盘；返回值字段与 `computer_virtual_click` 完全一致，仅 `action` 取值不同（`real_click`）。
- **`computer_type`（键盘输入）** —— 把字符串**逐字符真实敲入**当前聚焦的输入框（触发真实键盘事件）。仅支持 ASCII 可打印字符与空格；`\n`/`\r` 触发回车、`\t` 触发 Tab；中文等非 ASCII 不支持（应改用剪贴板粘贴等）。输入结束后等待 0.1s 截取**未标注**画面注入并落盘。

## 典型用途
- **虚拟点击用于预演**：先 `computer_screenshot` 观察画面 → `computer_virtual_click(x, y)` 得到带标记图，无副作用地核对坐标是否命中目标。
- 确认落点无误、或用户明确要求真实操作后，再调用 `computer_click(x, y)` 执行真实点击 —— 坐标基于最近一张截图（虚拟点击带标记图或真实点击回传图）推算。
- **输入文本**：先用 `computer_click` 点进目标输入框使其聚焦，再用 `computer_type("...")` 逐字符输入 ASCII 文本；输入结束自动回传画面，据此判断是否输入正确、是否需按回车提交。
- 需要反复核对坐标时用虚拟点击最安全，不会误触发真实应用行为。

## 真实点击前请自查
- 目标坐标是否来自最新一张可见截图？位置变动过大时先重新 `computer_screenshot`。
- 是否存在可能误触（删除/提交/转账/发送等高风险按钮）？不确定时先 `computer_virtual_click` 试算并向用户说明。

## 注意事项
- 截屏覆盖**主显示器**；坐标是整块屏幕坐标（含任务栏/停靠栏）。
- `computer_virtual_click` 永不执行真实操作；要在系统里真正执行一次点击请用 `computer_click`，不要混淆二者。
- 每张截图都会进入上下文，连续反复截屏会快速消耗上下文；能依据上一次回传画面判断时就不要重复截屏。
- 截图保存在工程内 `.computer_use/` 目录（git 不跟踪），`saved_file` 字段返回其绝对路径，需要时可打开核实。
